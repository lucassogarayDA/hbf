Un archivo. Todo tu contenido.

HBF guarda texto, binario, metadatos, listas y bloques especializados en un solo formato de texto plano, editable desde una terminal.

Qué guarda un .hbf

Cada bloque cumple un rol distinto dentro del mismo archivo. Tocá cualquiera para ver el detalle.

El bloque [TEXTO] guarda contenido de texto libre: notas, párrafos, secciones completas. Es el bloque más simple del formato y el que arranca en cualquier archivo nuevo.
El bloque [METADATOS] guarda un objeto JSON con información estructurada del archivo: título, autor y fecha de creación. Se edita como cualquier otro bloque, sin tocar el resto del archivo.
Guarda imágenes y otros archivos binarios codificados en base64 dentro del bloque [IMAGEN], junto con hash, dimensiones y formato. También se puede guardar y extraer cualquier archivo binario suelto como bloque independiente.
El bloque [LISTAS] organiza elementos línea por línea, pensado para tareas, pasos o ítems sueltos, en el mismo formato de texto plano que el resto del archivo.
El bloque [NUMERICO] guarda arrays y estructuras de datos numéricos en formato JSON, útil para series de datos chicas que no ameritan un archivo aparte.
Cifra el archivo completo con Fernet (AES-128 simétrico) usando una clave derivada de tu contraseña vía PBKDF2-HMAC-SHA256 con 100.000 iteraciones. Genera un archivo .enc aparte; el original no se borra automáticamente. Requiere la librería cryptography.
Convierte un .hbf a TXT, JSON, MD, XML, CSV, YAML, HTML, INI o TOML, según lo que necesites para llevarte el contenido a otra herramienta.
Detecta el formato por extensión y convierte a .hbf archivos TXT, JSON, XML, YAML, TOML, INI, CSV, MD o HTML, para empezar a usar HBF con contenido que ya tenías en otro lado.
HBF está completamente traducido a 12 idiomas: español, inglés, portugués, francés, alemán, italiano, japonés, chino, ruso, coreano, árabe e hindi. Todos los mensajes, opciones y el menú están traducidos al 100% sin depender del español como respaldo.
Un mismo código detecta el sistema operativo y se adapta: pensado para Termux en Android, y funcional también en Linux y Windows.

Instalación

Requiere Python. El cifrado necesita además la librería cryptography.

pip install hbf-hyper

📂 Probar HBF

Subí un archivo .hbf y mirá su contenido en vivo.
